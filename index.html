15 Shadows · 轻径向
阴影仅用于增强实体感、空气感、呼吸感 · 装饰性阴影 = 视觉噪音，禁止
Rule: 只有 2 级阴影：Air（空气感，静态实体）与 Lift（呼吸感，hover 浮起）。大模糊半径 + 负 spread（-8px/-14px）让阴影径向弥散、边缘消失。禁止用阴影做层级堆叠装饰——层级靠间距和背景色表达。
Air · 实体感 · 0 1px 3px 0.04 + 0 6px 20px -8px 0.05
Lift · 呼吸感 · 0 2px 6px 0.05 + 0 14px 36px -14px 0.10
红色唯一性：红色（#B73A3A）仅用于真正的破坏性操作——清空数据、删除、不可恢复的确认。关闭按钮、取消使用主题反色（--inverse），错误状态仍使用危险语义色。

E3 Light Awareness · Global
Light has direction and warmth — surfaces respond to a virtual light source
Rule: Light comes from top-left. All surfaces show: top edge highlight (inner glow), bottom edge shadow (subtle border darkening). Consistent across every component, every product.
Surface
Radial highlight from top-left. Pure and clean.
Secondary
Warmer tone, same light direction.
Tertiary
Deeper recess, light barely reaches.
Light Formula: Every surface = base color + radial-gradient highlight (top-left 30%/20%) + 1px border (lighter top, darker bottom) + inset shadow (white highlight top, 0.5~0.7 opacity). Dark mode: reduce highlight to 0.03~0.05 opacity, increase shadow depth.
E4 Morphing · One Button, Two Faces
Click the + button — it rotates and morphs into × (one element, fluid transform)
Rule: If one button can morph, don't use two. Plus → X via rotation. The horizontal line shrinks away, vertical line rotates 45°. Same DOM element, fluid transition.

E9 Inertial Dual Ring Spinner
Concentric outer and inner rings · Independent acceleration and coasting
Rule: The outer and inner rings rotate independently with alternating acceleration and inertia. Use for page-level loading and preserve a readable status.

Part V · 适配 Adaptation — Concise 环境响应
30 Theme & Adaptation
Light / Dark dual mode · Responsive breakpoints · Accessibility-first
☀️
Light Mode
Warm surfaces, inset highlights, soft shadows. Ceramic warmth at full expression.
🌙
Dark Mode
Deep surfaces, accent glow intensified, shadows layered. Light awareness reduced to 3%.
♿
Accessibility
WCAG AA contrast ≥ 4.5:1. Focus-visible rings. prefers-reduced-motion respected.
Responsive: Mobile ≤ 600px (single column) · Tablet 600-1024px (2 columns) · Desktop > 1024px (full grid). Window constraints: min 360×640, recommended 1280×720+.
Motion: All animations respect @media (prefers-reduced-motion: reduce). When active, transitions snap to instant, breathing pauses.

Shared semantics and quality gates, distinct product expression
Boundary: Simcise publishes a one-way token contract. Products adopt it only in their own planned migration; this repository never rewrites Route or Yuich.
