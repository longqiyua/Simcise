# Simcise Optional Enhancements

Enhancements are optional. Apply at most one signature treatment per view unless the product already defines a combination. Foundation quality always wins over atmosphere.

| ID | Enhancement | Use when | Avoid when |
|---|---|---|---|
| E1 | Breathing | one calm idle status benefits from subtle life | data-dense views, reduced motion |
| E2 | Ceramic | a primary warm surface needs tactile identity | Route, tables, repeated list rows |
| E3 | Light awareness | the full page uses one coherent virtual light source | strict flat themes or immersive media |
| E4 | Morphing action | one control reversibly changes purpose in place | toolbars with many actions |
| E5 | Soft-light toggle | a small settings surface benefits from restrained on-state glow | standard checkboxes or dense forms |
| E6 | Dynamic cursor | a signature single-line input justifies custom caret behavior | textareas, code editors, accessibility risk |
| E7 | Inertial ring spinner | branded page-level waiting | inline button loading |
| E8 | Glass | a small transient floating surface needs background separation | large backgrounds, low-performance devices |
| E9 | Inertial dual-ring spinner | branded page-level waiting instead of E7 | inline button loading or reduced motion |

Before adding one, state its task or brand reason. Provide a reduced-motion and low-performance fallback. Route's adapter remains strictly flat and does not use E1–E3 or E8 by default.
